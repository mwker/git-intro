# Git Intro Project

Ce dépôt est mon premier projet Git réalisé dans le cadre du programme Holberton School. Il m'a servi à découvrir les commandes de base de Git et le travail avec des branches.

## Objectifs

- Initialiser un dépôt Git et faire des commits.
- Créer des branches pour développer des fonctionnalités séparément.
- Fusionner des branches et ouvrir des pull requests sur GitHub.
- Ignorer certains fichiers avec un `.gitignore`.
